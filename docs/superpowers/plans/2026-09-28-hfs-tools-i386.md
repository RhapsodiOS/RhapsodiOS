# HFS Tools for i386 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `newfs_hfs`, `hfs.util` and `VDI-interface` (the rest of `src/hfs-1`) for i386, with `newfs_hfs` and `hfs.util` handling HFS's big-endian on-disk format and verified on the QEMU i386 guest.

**Architecture:** `newfs_hfs` builds B-tree nodes and catalog records big-endian directly and swaps its host-order MDB and volume header as a whole around the writes that put them on disk (diskdev_cmds-143 `makehfs.c`). `hfs.util` swaps each field where it reads it (hfs-226.1.1 `hfsutil_main.c`). Both edits are made by two checked patch scripts committed beside this plan. The existing guest harness gains `probe` and `newfs` modes; the host checker is the oracle.

**Tech Stack:** C (Apple cc on Rhapsody), `rbuild` on the private QEMU i386 guest, Python 3 host harness (`vm/hfs_guest.py`, `tools/hfsimg`), pytest.

**Spec:** `docs/superpowers/specs/2026-09-28-hfs-tools-i386-design.md`

## Global Constraints

- Branch `hfs-tools` in worktree `D:\RhapsodiOS\.worktrees\hfs-endian`, from master `a3e168ea6`.
- On ppc every byte-order macro is an identity and the whole-structure swaps are empty; ppc builds as before.
- Only `newfs_hfs` and `hfs.util` change code; `hfs_glue` (`VDI-interface`) only has to build.
- Out of scope: 1024-byte-sector partitions, ppc runs, `hfs.util` mount/unmount and `kl_com`, `hfs_glue` behaviour.
- `hfs.util -p` success is `FSUR_MOUNT_HIDDEN` (-9), exit status 247; the label goes to `/usr/filesystems/hfs.fs/hfs.label`, a directory `golden.img` lacks.
- Legacy sources hold Mac-Roman bytes: never edit them with the Edit tool. Existing sources change only through the committed patch scripts or `tools/latin1_replace.py`, and every diff is read with `git diff | cat -A` for whitespace changes.
- Commit messages: `subsystem: what it does`, one or two lines, no trailers.
- Guest work: one foreground SSH session per box operation (`vm/guest-remote.ps1 -Run`), run as a Bash background command; never poll the guest in a loop.

## Review Focus

1. **A volume large enough to need B-tree map nodes.** `WriteMapNodes` runs only when a tree outgrows its header's map (HFS catalogs past about 2160 512-byte nodes); a big HFS volume should still check clean. Pinned by the 2 GB `newfs -H` run in Task 3.
2. **HFS Plus with 512-byte allocation blocks.** `InitVolumeHeader` burns blocks around the headers and `MarkBitInAllocationBuffer` marks two bitmap bits, possibly in different sectors. Pinned by the `newfs-hfsplus512` flavour in Task 3.
3. **A disk that is not HFS.** `hfs.util -p` on it must answer "unrecognized" (-2, exit status 254) and write no label, not claim it or crash. Pinned by `probe-blank` in Task 4.
4. **A volume name that is not ASCII.** It must reach `hfs.label` as the same name (UTF-8, compared after NFC). Pinned by probing a volume built with the name `Café Test` in Task 4.
5. **A catalog in more than eight extents.** `hfs.util` then reads the extents B-tree (`GetCatalogOverflowExtents`). No built or Apple volume has one, and the builder cannot make one; the swaps there are covered only by reading. Recorded in the Outcome as untested.

```python
def _files_loop():
    return ("while [ $i -lt %d ]; do n=`printf %%03d $i`; P w/f$n `expr $i \\* 1499 %% 30000`; "
            "i=`expr $i + 1`; done" % NEW_FILES)


def _dirs_loop():
    return ("while [ $i -lt %d ]; do n=`printf %%02d $i`; mkdir w/d$n; P w/d$n/x 100; "

def _append_lines():
    return [
        "A() { %s \"$1\" $2 >> \"$1\"; }" % _PERL,

def fresh_manifest():
    """What newfs_script leaves on the empty volume newfs_hfs made."""
    man = [("dir", "w")]
    for i in range(NEW_FILES):
        man.append(("file", "w/f%03d" % i, new_file_size(i)))
    for i in range(NEW_DIRS):

        man.append(("file", "w/d%02d/x" % i, 100))
    man.append(("file", "w/big", BIG_SIZE))
    man.append(("file", "w/ga", APPEND_ROUNDS * APPEND_CHUNK))
    man.append(("file", "w/gb", APPEND_ROUNDS * APPEND_CHUNK))

def newfs_script(device, raw_device, flags):
    """Format the disk with newfs_hfs, then mount the new volume and fill it."""
    lines = [
        "O=/mnt/out.txt",
        "echo BEGIN > $O",
        "ln -sf /dev/hd1a /dev/hd1_hfs_a",
        "/mnt/newfs_hfs %s-v %s %s >> $O 2>&1; echo \"newfs rc=$?\" >> $O"
        % (flags, NEWFS_NAME, raw_device),
        "/mnt/mount_hfs %s %s >> $O 2>&1; echo \"mount rc=$?\" >> $O" % (device, MOUNT_POINT),
        "cd %s || exit 1" % MOUNT_POINT,
        "P() { %s \"$1\" $2 > \"$1\"; }" % _PERL,
        "mkdir w",
        "i=0",
        _files_loop(),
        "i=0",
        _dirs_loop(),
        "P w/big %d" % BIG_SIZE,
    ] + _append_lines() + ["echo \"ops done\" >> $O"] + _report_lines() + _finish_lines()
    return "\n".join(lines) + "\n"


# --- hfs.util's probe ------------------------------------------------------------

LABEL_FILE = "/usr/filesystems/hfs.fs/hfs.label"


def probe_script(dev_arg):
    """hfs.util -p, its exit status, and the label it wrote.  golden.img has no
    hfs.fs directory, and a label left by an earlier probe must not count."""
    lines = [
        "O=/mnt/out.txt",
        "echo BEGIN > $O",
        "mkdir -p /usr/filesystems/hfs.fs",
        "rm -f %s" % LABEL_FILE,
        "/mnt/hfs.util -p %s removable writable >> $O 2>&1; echo \"probe rc=$?\" >> $O" % dev_arg,
        "cat %s > /mnt/label.txt 2>> $O" % LABEL_FILE,
        "echo \"report done\" >> $O",
        "sync",
        "echo END >> $O",
        "sync",
    ]
    return "\n".join(lines) + "\n"
```

```python
def volume_name(hfs_img):
    with open_volume(hfs_img) as v:
        return nfc(v.name_str(v.entries()[volume.ROOT_FOLDER_ID].name))


def verify_probe(hfs_img, results, expect_ok=True):
    """hfs.util -p must name an HFS volume, and must refuse anything else."""
    out = results["out.txt"] or ""
    label = results.get("label.txt")
    problems = []
    if "END" not in out:
        problems.append("guest never reported 'END'; out.txt: %r" % out)
    if expect_ok:
        if "probe rc=%d" % PROBE_OK not in out:
            problems.append("hfs.util -p did not return FSUR_MOUNT_HIDDEN; out.txt: %r" % out)
        want = volume_name(hfs_img)
        got = nfc((label or "").strip("\n"))
        if got != want:
            problems.append("hfs.util label %r, but the volume is named %r" % (got, want))
    else:
        if "probe rc=%d" % PROBE_UNRECOGNIZED not in out:
            problems.append("hfs.util -p did not return FSUR_UNRECOGNIZED; out.txt: %r" % out)
        if label:
            problems.append("hfs.util wrote a label for a disk that is not HFS: %r" % label)
    return problems


def newfs_problems(flavour, hfs_img, out):
    """newfs_hfs must have made the kind of volume it was asked for."""
    if "newfs rc=0" not in out:
        return ["newfs_hfs failed; out.txt: %r" % out]
    problems = []
    try:
        with open_volume(hfs_img) as v:
            if v.plus != (flavour != "hfs"):
                problems.append("newfs_hfs made %s" % ("HFS Plus" if v.plus else "HFS"))
            if flavour in NEWFS_BLOCK and v.block_size != NEWFS_BLOCK[flavour]:
                problems.append("newfs_hfs made %d-byte blocks, not %d"
                                % (v.block_size, NEWFS_BLOCK[flavour]))
            print("  newfs_hfs made: %s, %d-byte blocks, %s" % (
                "HFS Plus" if v.plus else "HFS", v.block_size,
                "wrapped" if v.wrapper is not None else "no wrapper"))
        name = volume_name(hfs_img)
    except Exception as e:      # a volume this broken is itself the finding
        return ["the new volume does not open: %s" % e]
    if name != scenario.NEWFS_NAME:
        problems.append("the new volume is named %r, not %r" % (name, scenario.NEWFS_NAME))
    return problems
```

```sh
#!/bin/sh
# One session on the private i386 guest: wait for other rbuilds, make sure
# hfs-1's dependencies are in /build/repo, build hfs-1 for i386 and pull the
# tools out of the apk.
R=/build/hfsle

mkdir -p $R/state-hfs
for p in driverTools-1:drivertools drivers-i386/ide/drvEIDE:drveide Commands/diskdev_cmds:diskdev-cmds; do
    src=`echo $p | sed 's/:.*//'`; pkg=`echo $p | sed 's/.*://'`
    if ls /build/repo | grep "^$pkg-[0-9].*-i386.apk" > /dev/null; then continue; fi
    rbuild buildpackage --state $R/state-hfs $TC --dir --target all $R/src/$src /build/repo /build/repo > $R/dep-$pkg.log 2>&1
    echo "$src rc=$?"
done
rm -rf $R/out-hfs && mkdir -p $R/out-hfs
rbuild buildpackage --state $R/state-hfs $TC --dir --target all $R/src/hfs-1 /build/repo $R/out-hfs > $R/hfs.log 2>&1
echo "hfs-1 rc=$?"
grep -n 'rror\|No rule\|cannot\|undefined' $R/hfs.log | grep -v 'warning\|javaconfig\|(ignored)' | tail -30
A=`ls $R/out-hfs/hfs-*.apk 2>/dev/null | head -1`
[ -n "$A" ] || { echo NO_APK; tail -20 $R/hfs.log; exit 1; }
gzip -dc $A | tar tf - | grep -v '/$'
rm -rf $R/x-hfs && mkdir -p $R/x-hfs && cd $R/x-hfs && gzip -dc $A | tar xf -
for f in `find . -type f -perm -100`; do echo "$f: `lipo -info $f 2>&1 | sed 's/.*: //'`"; done
```
