# Source lineage

- **NetBSD `auich` / `ac97`** — register maps, codec helpers, and ICH bus-master
  DMA patterns informed the controller and codec layers.
- **openstep-ac97** — AC97 register protocol confirmation only; no code copied.
- **Rhapsody `ioPorts.h`** — port-first I/O access style used throughout.
