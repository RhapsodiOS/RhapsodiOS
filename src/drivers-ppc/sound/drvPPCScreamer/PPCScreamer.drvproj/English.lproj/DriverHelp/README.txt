PPC-only Screamer DAVbus audio. Probe requires one consistent Screamer identity, complete firmware routing and rates, three validated resource ranges and interrupts, and the KeyLargo DAVbus backend. Unsupported or ambiguous firmware is declined before hardware access. PCM is 16-bit big-endian stereo. Driver-local power callbacks require system PPC PM integration before physical sleep/wake is supported. Unload is unavailable because IOAudio worker threads retain the instance. Physical hardware validation is pending; see VALIDATION.md.
