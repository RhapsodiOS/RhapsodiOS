The changed AWACS probe translation unit compiles with the period compiler.
The whole legacy bundle fails on its existing undeclared `_entry` references

Physical audio, exactly-one-driver attachment on a machine, and physical
sleep/wake remain untested. PPC `APM.c` returns `PM_R_BAD_STATE` for power-state
requests and provides no events; local callback tests cannot pass system PM.

After the fresh branch review, code commit `289928f46` was rebuilt and tested.
The corrected integration reads raw firmware entries (including unpublished
codec children), normalizes Sawtooth's interrupt tuples before DriverKit
publication, and validates DriverKit's transformed interrupt identities.
The full runtime activation acquires platform ownership before quiescing DMA.
A failed initial stop retains its quiescence obligation through close.

The updated kernel's `pmap_set_cache_spec` is required. It accepts only an
exclusively mapped, wired kernel page; drains/invalidates its cached contents,
invalidates the PTE and TLB entry, updates physical-page and PTE WIMG, and
republishes the mapping. Rejected pages stop activation. Descriptor pages remain
private and cache policy is restored before any release. The old kernel's
cache-spec function ignored the policy and cannot support this bundle safely.
The actual provider body is tested with instrumented PTE/cache/TLB operations;
this is a host model of the provider, not execution of PPC cache instructions.
Its PPC object was rebuilt after explicitly removing the old object (host/guest
mtime differences otherwise made the legacy make consider it current):

```
cd /tmp/screamer-source/src/kernel-7/BUILD/RELEASE_PPC
rm -f pmap.o
CONFIG_DIR=/build/tools/bin MIGCOM_DIR=/build/tools/libexec \
PATH=/build/tools/bin:/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin gnumake pmap.o
```

`nm pmap.o` defines `_pmap_set_cache_spec`; the new bundle references that symbol.
