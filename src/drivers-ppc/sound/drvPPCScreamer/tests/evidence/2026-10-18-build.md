# Native build evidence, 2026-10-18

Compiler: Apple cc-771.4, GCC 2.7.2.1, using the period PPC backend in a
Rhapsody i386 snapshot guest. Guest name `screamer-native`, SSH 2283, QMP 4683.
No PPC hardware or audio device was emulated or loaded.

SDK: `NEXT_ROOT=/build/bootstrap-root`, with kernel headers installed from this
branch and overlaid on the existing SDK; DriverTools resources came from the
guest's installed `/System/Developer/ProjectTypes`. Makefiles used
`MAKEFILEPATH=/System/Developer/Makefiles`.

Header installation, from the transferred `src/kernel-7`:

```
CONFIG_DIR=/build/tools/bin MIGCOM_DIR=/build/tools/libexec \
PATH=/build/tools/bin:/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin \
gnumake installhdrs DSTROOT=/tmp/screamer-dst RC_ARCHS=ppc \
  DECOMMENT=/build/tools/bin/decomment
```

Exit 0; installed `PEDAVBus.h` compared byte-for-byte with source. Period PPC
`pmap.o` and `vm_kern.o` compile and expose global `pmap_enter_cache_spec`,
`kernel_map`, `kmem_alloc_wired` and `kmem_free` symbols.

Platform Expert was cleaned and built with `RC_ARCHS=ppc`, the SDK and makefile
paths above. `lipo -info` reports PPC; `nm` shows definitions of
`PEDAVBusGetInfo`, `PEDAVBusSetState` and `PEDAVBusSetAmplifier`.

`package-source.sh` generated `/tmp/screamer-acceptance/run5` without any built
config bundle. Running its root Makefile with the same PPC/SDK flags built
`PPCScreamer.config/drvPPCScreamer_reloc`. `lipo -info` reports only PPC and
`otool -hv` reports `MH_MAGIC PPC ALL PRELOAD`. The generated table contains
one `Server Name = drvPPCScreamer`, matching the generated kernel-server class.

Host verification: 287 Screamer C checks pass under strict C89; all existing
TAS C tests pass using 32-bit-long native clang; all Platform Expert host suites
pass, including 85 DAVbus checks. The period Objective-C runtime passes tests
of the actual adapter selector, tree-matcher, IRQ and period-service methods
using IOAudio/IOPropertyTable doubles. Kernel probe, mapping, timer allocation
and worker-publication paths are compile checked, not runtime validated.

The isolated source staging tests check helper byte equality, unchanged source
files, omitted stale config products and rejection of a nonempty destination.

`rbuild buildpackage --arch ppc` reached dependency resolution and failed with
`unable to find dependency for "drivertools"` in `/build/repo`. The same source
with `--arch i386` was rejected before compilation for its PPC package
architecture. No APK acceptance is claimed.

The changed AWACS probe translation unit compiles with the period compiler.
The whole legacy bundle fails on its existing undeclared `_entry` references
in `PPCSoundPrivate.m`; it has no verified whole-bundle result here.

Physical audio, exactly-one-driver attachment on a machine, and physical
sleep/wake remain untested. PPC `APM.c` returns `PM_R_BAD_STATE` for power-state
requests and provides no events; local callback tests cannot pass system PM.
